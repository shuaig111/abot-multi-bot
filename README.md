# ABot · 多 Bot 协作空间

一个微信聊天界面风格的多 Bot 协作插件：每个 Bot 拥有独立单聊空间，可自由拉入群聊协作，支持任务自动对接与多模型切换。

## 功能特性

- **多 Bot 管理**：不限数量新建 Bot，每个可自定义名称与颜色（22 预设色 + 取色器 + hex）。
- **独立单聊空间**：每个 Bot 有私有的聊天与项目空间，互不干扰。
- **群聊协作**：新建群聊、拉入已有 Bot、动态增删成员；群内发消息成员逐个应答。
- **任务对接**：群聊发布含关键词的任务，对应 Bot 自动"接单"并把任务挂到自己的项目清单。
- **多模型切换**：默认 DeepSeek，支持 27+ 主流模型（国内优先）及自定义 OpenAI 兼容接口。
- **插件化**：可导出为 AI 插件（MCP 配置），可嵌入其他 AI 界面，并能随时切回本体 AI 主页。

## 目录结构

```
abot/
├── SKILL.md            # WorkBuddy 技能说明（元数据 + 使用方式）
└── assets/
    └── index.html      # 完整单文件应用（纯 HTML/CSS/JS，离线可用）
```

## 使用方式

1. 双击打开 `assets/index.html`，或在浏览器中打开。
2. 右上角「＋」新建 Bot / 群聊；点 Bot 进入单聊，点群聊进入协作群。
3. 聊天页顶部「模型」切换底层大模型，「项目」查看任务看板，「＋ 拉入 Bot」管理群成员。

## 安装为 WorkBuddy 技能

将整个 `abot/` 目录放入 `~/.workbuddy/skills/` 下即可。之后在对话中提及「多 Bot 协作 / ABot / Bot 群聊」等会触发该技能。
